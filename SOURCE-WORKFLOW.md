# Source and distribution

The authoritative maintained source is [this Nostr repository](https://gitworkshop.dev/npub17j3f7cuhcvjqnf7d80x6rt9hmkkhdguwg4l2th0h4qnhqketr63s6xakwv/git.shakespeare.diy/openstays). The designated passive [GitHub mirror](https://github.com/murdawkmedia/openstays) must have Actions disabled. Verify its public availability, owner identity and exact mapped refs on each reviewed mirror update. Continue maintained work on main. Review the exact outgoing history and refs before each manual mirror update; do not add automatic deletion or deployment propagation.

The existing Murdawk Media repository is retained as the passive mirror, with its original archive flag and historical branches preserved. Original branches and tags are preserved where eligible; archived GitHub pull-request records retain their original URLs. New contribution/release work must use the maintained source and the destination appropriate to its upstream. No application lifecycle or upstream deployment change follows merely from this source migration. Read the existing project README for build, test and runtime requirements.

Published history replaces private operational paths with generic workspace references. Complete original history remains in private recovery. The separate private production repository and its deployment are outside this public-source migration.
