# Source and distribution

The authoritative maintained source is [this Nostr repository](https://gitworkshop.dev/npub17j3f7cuhcvjqnf7d80x6rt9hmkkhdguwg4l2th0h4qnhqketr63s6xakwv/git.shakespeare.diy/openstays). The designated passive [GitHub mirror](https://github.com/hilaryduffrules-hash/openstays) must have Actions disabled. Verify its public availability and exact refs before archiving the former repository. Continue maintained work on main. Review the exact outgoing history and refs before each manual mirror update; do not add automatic deletion or deployment propagation.

The former MurdawkMedia repository is retained as an archived historical source after source, recovery and applicable runtime checks. Original branches and tags are preserved where eligible; archived GitHub pull-request records retain their original URLs. New contribution/release work must use the maintained source and the destination appropriate to its upstream. No application lifecycle or upstream deployment change follows merely from this source migration. Read the existing project README for build, test and runtime requirements.

Published history replaces private operational paths with generic workspace references. Complete original history remains in private recovery. The separate private production repository and its deployment are outside this public-source migration.
