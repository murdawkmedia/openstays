Inside the source

A useful foundation.
With the edges made clear.

OpenStays brings the guest flow and property operations into one codebase. Run it for your own property and choose the services you connect.

01 / BOOKING

Availability with a transactional core

Booking holds and occupied nights change together. Rate rules, stay limits and turnover buffers belong with the property.

02 / PAYMENTS

Your provider, behind an interface

Stripe and Square integrations live in the source. Configure and verify your own checkout, webhooks and refund flow before taking money.

03 / STAFF

Operations with property-scoped roles

Front desk, housekeeping, maintenance, folios and night audit have feature-gated foundations, with explicit roles and audited actions.

04 / CALENDARS

Per-unit iCal, in and out

Import external calendar blocks and export unit calendars. Polling is not an instant cross-platform lock; staff still resolve conflicts.

05 / AUTOMATION

API, command line and MCP

Connect tools to the same booking rules. Scoped API keys, a standalone CLI and an MCP server provide an automation surface.

06 / OWNERSHIP

Property data outside the code

Your inventory, staff and guest records belong in your own backend. The public repository contains code and fictional fixtures.

An early-stage project, not a managed booking platform. Channel-provider certification, real inventory setup, provider credentials, security review, backups and live acceptance belong to each operator deployment. The experimental hackathon layer is separate from the reduced production profile.

A few good questions

Open source.
Plain answers.

What the project does, what you can host, and what still needs an operator behind it.

What is OpenStays?

OpenStays is MIT-licensed, open-source booking and property-management software for independent lodging. Its source includes a guest reservation flow, availability checks, staff operations and integration points. This website is a static project showcase, not a hosted reservation service.

Who is OpenStays for?

OpenStays is designed for operators and developers working with cabins, campgrounds, RV sites, glamping, yurts and small resorts. Each operator runs a separate deployment and supplies their own property inventory, rates and policies.

Can I self-host OpenStays?

Yes. You can host the static frontend on Cloudflare or another static host and run a fresh backend with Convex Cloud or the self-hosted Convex backend. Fully self-hosted operation requires your own infrastructure, backups and maintenance. The project site needs no backend.

Is OpenStays free?

The OpenStays code is available under the MIT license, with no software license fee from this project. Hosting, payment processing, email and optional provider services can cost money. It is software you operate, not a free managed booking service.

Does it replace a booking platform or channel manager?

OpenStays is an alternative foundation for direct bookings and property operations. The source includes per-unit iCal import and export. Direct Airbnb, Booking.com and Expedia channel connectivity requires a separately configured provider, partner access and acceptance; it is not included as an activated service.

Can I make a real booking on this website?

No. All calendars, prices and reservations shown here are fictional examples. The project site has no booking backend. To accept real stays, deploy your own instance, configure inventory and providers, and verify the complete booking, payment, cancellation and recovery flows.
